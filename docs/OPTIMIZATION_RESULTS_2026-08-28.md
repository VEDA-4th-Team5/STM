> 2026-08-28 / EVDA-218, EVDA-46
> 대상: STM1 노드 펌웨어 (STM32F401RE, 84MHz, FreeRTOS)
> 원인 분석은 [`FLASH_FOOTPRINT_2026-08-27.md`](FLASH_FOOTPRINT_2026-08-27.md) 참고

## 측정 방법

| 항목 | 방법 |
|---|---|
| 용량 | `arm-none-eabi-size` — 동일 툴체인·플래그로 전/후 각각 빌드 |
| 실행 시간 | Cortex-M4 내장 **DWT 사이클 카운터** (84MHz, 1 cyc = 11.9 ns) |
| 스택 | `uxTaskGetStackHighWaterMark()` 런타임 실측 |
| 힙 | `xPortGetFreeHeapSize()` 런타임 실측 |

전/후 비교는 `measure/EVDA-218-before` 와 `measure/EVDA-218-after` 두 브랜치에
**완전히 동일한 계측 코드**를 넣고 각각 구워서 얻었다.

### 부품 등급

| | 플래시 사용률 (F401RE 512K) | 최소 필요 파트 |
|---|---:|---|
| 전 | 25.4 % | STM32F401**RC** (256K) |

**플래시 등급 2단계 하향 가능.** 같은 F401 라인이라 핀맵·코드 변경 없이 교체된다.

> **"양산 시 RB 로 내려갈 수 있음을 확인했다"** 가 정확한 표현이다.

## 2. 성능

화재 태스크의 1초 창 처리 시간.

| 항목 | 전 | 후 |
|---|---:|---:|
| FFT 처리 (`arm_rfft_fast_f32` + `arm_cmplx_mag_f32`) | 14,706 cyc / **175 µs** | 14,702 cyc / **175 µs** |
| 창 전체 (샘플 합산 → FFT → 판정) | 18,942 cyc / **225 µs** | 18,893 cyc / **224 µs** |
| CPU 점유율 (1 Hz 주기) | 0.0225 % | 0.0224 % |
| 화재 태스크 스택 여유 | 572 B | 588 B |
| FreeRTOS 힙 여유 | 6,552 B | 6,552 B |

**연산량은 사실상 변하지 않는다.** FFT 는 energy 텔레메트리용으로 그대로 돌고,
없앤 것은 EMA 한 줄과 비교 몇 개뿐이다.

이 표의 의미는 "개선"이 아니라 **설계 여유의 근거**다 —
1초에 224 µs 만 쓰므로 CPU 의 99.98 % 가 놀고 있다.

측정 편차도 참고할 만하다. 8~9회 관측에서 `max − avg` 가 **2 사이클(24 ns)** 이었다.
1초 주기 태스크가 그만큼 결정적으로 도는 상태다.

## 3. 신뢰성

| 항목 | 전 | 후 |
|---|---|---|
| 부팅 후 오검출 | **간헐 발생** — 한 실행에서 60초 뒤 DETECTED 고착 | 없음 (140초+ 무검출) |
| 오검출 복구 | **불가** — baseline 동결로 구조적 고착 | 해당 없음 |
| 화재 감지 지연 | 판정 신뢰 불가 | **3초** (5창 중 3) |
| 화재 해제 지연 | 복구 안 됨 | **4초** (5창 중 1 이하) |
| 판정 진동 | 임계 근처에서 매 초 반전 | 없음 (히스테리시스) |

> 전 버전의 오검출은 **매번 재현되지 않는다.** 주변광 조건에 따라 나기도 하고
> 안 나기도 한다. 재현성이 없다는 점이 오히려 이 결함의 위험한 성질이다.

### 신호 분리도 (실측)

| | raw (ADC 12bit) |
|---|---:|
| 주변광 | 900 ~ 1,401 |
| 판정 임계 | 2,500 |
| 불꽃 (라이터 근접) | **4,083 ~ 4,092** (포화) |

임계까지 여유가 주변광 최대의 1.78배, 주변광 변동폭(180)의 6배다.

## 4. 부수 확인 — energy 는 판정에 쓸 수 없다

같은 실측에서 라이터를 댔을 때 1~20Hz 대역 에너지:

```
접근 순간   71.16     점화 스파이크
연소 중      0.02     <- 주변광(0.2 ~ 1.0)보다도 낮다
이탈 순간   77.95
```

센서가 포화되면 창이 평평해져 AC 성분이 사라진다.
**energy 만으로 판정했다면 연소 구간을 통째로 놓쳤다.**

energy 는 계속 계산해 FIRE 프레임으로 내보내되(Qt 대시보드 시각화용)
판정에는 쓰지 않는 현재 구조가 실측으로 뒷받침된다.
